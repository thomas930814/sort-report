🔀 合併排序法

合併排序法是一種分治法的排序演算法。它將數列分成兩個相等的部分，分別對其進行排序，然後將這兩個排序後的部分合併在一起。這個過程會遞迴地進行，直到整個數列被排序為止。

📋 操作原理

步驟 1：使用分治法，將數列分成兩個相等的部分。

步驟 2：遞迴地對左右兩部分進行排序。

步驟 3：將已排序的兩部分合併成一個有序數列。

🎬 過程示例

假設我們有一個數列：[5, 3, 8, 4, 2]

⏱️ 時間與空間複雜度

時間複雜度：

  • 最佳情況： O(n log n) — 分治法的優勢在所有情況都存在
  • 最差情況： O(n log n) — 需進行 log n 層的分割和合併
  • 平均情況： O(n log n)

空間複雜度： O(n) — 需要額外的空間來存儲合併過程中的臨時數據
