# bubble-report
氣泡排序法是一種簡單的排序演算法。它重複地遍歷要排序的數列，依次比較相鄰的元素，並在順序錯誤的情況下交換它們。這個過程會重複進行，直到沒有需要交換的元素為止。
# selection-report
選擇排序法是一種簡單的排序演算法。它每次從未排序的元素中選擇最小的元素，放到已排序部分的末尾。這個過程會重複進行，直到所有元素都被排序為止。
# merge-report
合併排序法是一種分治法的排序演算法。它將數列分成兩個相等的部分，分別對其進行排序，然後將這兩個排序後的部分合併在一起。這個過程會遞迴地進行，直到整個數列被排序為止。
# insertion-report
插入排序法是一種簡單的排序演算法。它把元素分為已排序和未排序兩部分，每次從未排序部分取出一個元素，並將其插入到已排序部分的正確位置。這個過程會重複進行，直到所有元素都被排序為止。
# quick-report
快速排序法是一種高效的分治法排序演算法。它選擇一個基準元素，將數列分成小於基準和大于基準的兩部分，然後對這兩部分遞歸地進行排序。

# 學習心得
在學習各種排序法（Selection Sort、Insertion Sort、Merge Sort、Bubble Sort）的過程中，我發現每一種演算法其實都有其存在的價值，而不是單純地分成「好」或「不好」。
一開始接觸排序時，我覺得像選擇排序和泡泡排序這類時間複雜度為 O(n²) 的方法效率很差，但實際理解後，才發現它們的優點在於概念簡單、容易實作，對於初學者建立演算法思維非常重要。例如選擇排序讓我理解「從未排序區間中找最小值」的概念，而泡泡排序則讓我熟悉「透過交換逐步逼近正確結果」的過程。
插入排序則讓我體會到「資料特性會影響演算法效率」這件事。當資料已經接近排序完成時，它的效率可以大幅提升，甚至接近 O(n)，這讓我了解到選擇演算法時不能只看最壞情況，也要考慮實際使用情境。
至於合併排序，則讓我第一次接觸到分治法（Divide and Conquer）的概念。透過將問題拆解再合併，不僅提升效率到 O(n log n)，也讓我理解到更進階的演算法設計思維。不過它需要額外空間，也讓我意識到在設計程式時，時間與空間之間往往需要取捨。
整體而言，學習排序法不只是學會「怎麼排」，更重要的是理解不同方法背後的邏輯與適用情境。這讓我在面對問題時，可以根據需求選擇最合適的演算法，而不是一味追求最快或最簡單的方法。
